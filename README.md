# E-Commerce Customer Retention & Sales Analytics

## Project Overview

This project analyzes e-commerce sales performance and customer retention using SQL Server, Python, RFM analysis, and Power BI.

The project demonstrates an end-to-end data analytics workflow covering data cleaning, validation, customer segmentation, business KPI analysis, dashboard development, and Python-based automation.

## Business Objectives

- Analyze overall e-commerce sales performance
- Identify sales trends across time
- Analyze sales by category and region
- Understand new and returning order patterns
- Segment customers based on purchasing behavior
- Identify Champions, Loyal Customers, Potential Loyalists, At Risk, and Lost Customers
- Automate customer RFM analysis using Python
- Build an interactive Power BI dashboard for business analysis

## Data Preparation

The e-commerce dataset was loaded into SQL Server staging tables and validated for data-quality issues.

The following issues were identified and handled:

- Missing Customer IDs
- Invalid quantities
- Negative sales amounts
- NULL sales amounts
- Missing categories
- Duplicate order records

After cleaning and validation, the final dataset contained **4,993 valid records**.

## RFM Customer Analysis

Python and Pandas were used to calculate RFM metrics for each customer.

### RFM Metrics

**Recency**

Number of days since the customer's most recent order.

**Frequency**

Number of unique orders placed by the customer.

**Monetary**

Total sales amount generated by the customer.

### RFM Scoring

Customers were assigned scores from 1 to 5 for:

- Recency
- Frequency
- Monetary

The three scores were combined to create an overall RFM Score.

### Customer Segmentation

## Automation

The project includes a Python automation pipeline.

The Python script:

1. Connects to SQL Server
2. Extracts cleaned e-commerce data
3. Calculates RFM metrics
4. Generates RFM scores
5. Assigns customer segments
6. Updates the RFM CSV output

The Python output file is:

`rfm_customer_analysis.csv`

Windows Task Scheduler is configured to execute the Python script automatically on a daily schedule.

This allows the customer RFM analysis file to be regenerated automatically from the SQL Server data.
